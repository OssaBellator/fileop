# Security

## Reporting a security issue

Please do **not** disclose suspected vulnerabilities, credentials, private keys, tokens, personal data, or exploit details in a public issue.

Prefer GitHub's private security-advisory/reporting flow for this repository when it is available. Otherwise, open a minimal public issue that contains no sensitive details and asks for a private contact path.

## Scope

Security reports should describe the affected component, the observed behavior, and the smallest safe reproduction information needed to understand the issue.

A test, validation path, safety boundary, or documented invariant in this repository does not imply that every deployment environment or integration has received the same validation depth.
